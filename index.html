QC Research Vault Backup is a privately operated utility for manually controlled, resumable Google Drive archive backups and integrity checks.

Learn how data is handled →
01 / SOURCE PROTECTION

Read-only originals

The workflow accesses the source archive with read-only credentials. It does not modify or delete source files.

02 / INDEPENDENT STORAGE

Separate backup vault

Authorized copies are stored in a separate Google Drive account, not on this public website.

03 / VERIFICATION

Integrity checks

File identity, checksums, downloaded-copy verification, and checkpoints support reliable transfers.

About this application

The operator manually initiates inventory, directory creation, and copying stages through a private GitHub Actions workflow. The Google OAuth connection authorizes the backup account to create and verify files in its designated research vault. The requested Google Drive scope grants broader access than a single folder, so the account is dedicated to backup work and the workflow checks account and destination identity.

The application does not offer public accounts or archive downloads and is not an official product of QuantCrawler, Discord, Google, or GitHub.
